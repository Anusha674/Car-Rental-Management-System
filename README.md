# Car Rental Management System

A React based car rental management system built with Vite. This project provides a simple and responsive interface for browsing cars, viewing car details, booking vehicles, and managing rental related information.

## Features

- Browse available cars
- Filter cars by category and details
- View detailed car information
- Book a car using a booking modal
- User authentication modal
- Booking history modal
- Admin dashboard modal
- Responsive user interface

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React Icons
